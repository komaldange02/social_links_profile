# Social Links Profile

A responsive social links profile card built using HTML5 and CSS3.

## Overview

This project is a simple social profile card that displays:

- Profile image
- Name
- Location
- Short bio
- Social media links

The design is inspired by a Frontend Mentor challenge.

---

## Features

- Responsive card layout
- Hover effects on buttons
- Clean dark UI design
- Flexbox layout
- Rounded profile image
- Interactive social links

---

## Technologies Used

- HTML5
- CSS3
